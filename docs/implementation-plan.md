## 6. 验证清单

| 层次 | 必须覆盖 |
| --- | --- |
| 核心测试 | 坐标往返、缩放锚点、命中容差、基本几何与控制点 |
| 历史测试 | 拖拽合并、取消回滚、清空、重做分支、自定义状态、保存点 |
| 文档测试 | 数据往返、Unicode、数值精度、无效结构、版本与缺失插件 |
| Lua 测试 | 模块加载、实例隔离、回调错误、事务回滚、重载成功与失败 |
| 窗口验收 | 标签、系统文件对话框、输入焦点、高 DPI、窗口调整与资源清理 |
| 性能检查 | 代表性千级对象下的拖动、平移、缩放及批量绘制，区分计算和渲染耗时 |

性能检查先形成可复现数据，再决定是否增加缓存、裁剪或空间索引。首版不为未出现的十万级场景预建复杂渲染系统。
