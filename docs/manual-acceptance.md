# 可配置实例人工验收

从仓库启动 `out/Drawer/drawer.exe`。以下步骤覆盖可配置实例及整体平移。

## 多边形

1. 新建“多边形 / Polygon”，将顶点数设为 5；点击五个位置，应生成一个五边形并可继续绘制。
2. 勾选“自由顶点数”，点击至少三个位置，用 Enter、右键或“完成多边形”结束；Esc 取消未完成点列。
3. 切换调整模式，选中图形后应高亮并显示全部顶点；拖动顶点、取消、撤销和重做应正确恢复。
4. 绘制一部分后修改顶点数，旧预览应清除；设置只决定接下来新建的图形。

## 贝塞尔曲线

1. 新建“贝塞尔曲线 / Bezier”，设置 2 阶，点击三个控制点；再设 5 阶，点击六个控制点。
2. 两条曲线应保留各自阶数。调整模式中，选中后显示相应控制多边形，所有控制点均可拖动。
3. 调整采样点数观察选中曲线；绘制、拖动和撤销重做应按对象或一次拖拽进行。
4. 选择“曲线形式：闭合”，设置三阶，点击三个独立控制点即生成闭环；五阶点击五次。未完成时改变开闭设置应取消预览并提示，已完成曲线保持原状。
5. 调整模式顶部应直接看到选中曲线的阶数、“已闭合”及“断开接点”；画布接点只显示一个“起点/终点”手柄，拖动后曲线仍闭合，其他控制点可独立移动。
6. 点击“断开接点”，曲线暂时不变；拖原接点应拉开末端，起点保持不动。闭合/断开/拖动各一步撤销，撤销闭合可恢复原末端位置。
7. 选中旧的开口三阶曲线，点击“闭合曲线”，确认阶数不变且末端移到起点；一、二阶旧曲线只提示限制，不能闭合。新建一阶设置切换闭合时应升至三阶，并可整体撤销该设置变化。
8. 闭合曲线保存加载后仍可联动编辑；整体平移、Esc、撤销重做、多画布和应用脚本修改仍正常。

### 平滑接点（本轮已通过人工验收）

1. 新建闭合曲线后勾选“平滑接点”，三阶新建设置应自动变为四阶并提示；一次撤销同时恢复设置和阶数。四阶点击三个独立点自动完成，画布进度为 1/3、2/3。
2. 调整模式勾选选中曲线的平滑选项，检查接缝没有拐角，两侧控制点显示“切向”与辅助线。拖任一侧，另一侧应镜像联动；拖接点时两侧同时移动，其他控制点保持原位。
3. 取消平滑时形状不变，两侧可独立拖动；断开接点同时解除平滑。启用平滑可能改变形状，应可单步撤销；每次拖动一步历史，Esc 完整回滚。
4. 已有三阶曲线保持原阶数，只提示四阶限制。绘制时第二点与起点重合应提示重新落点；拖切向到接点时保留最后有效位置。已有对象两侧切向均与接点重合时，先拉开其中一个点再启用平滑。
5. 保存加载后仍可联动编辑；新建设置与选中对象设置互不影响，多画布、Gallery 与 F5 保持一致。普通闭合默认不勾选平滑。

## 图元与自定义对象

1. 新建 Gallery，应为空画布。选择“圆”，依次点击圆心和圆周点；切换“矩形”后点击两个对角点。
2. 选择“文本”，填写内容后点击画布；切到调整模式，从文字主体拖动。
3. 选择“自定义十字”，设置大小后单击放置；确认颜色、大小及控制点拖动。
4. 尝试折线/多边形的自由点数，以及贝塞尔阶数设置。切换图元应取消未完成预览并进入绘制模式。
5. “插入演示图元”应增加参考场景并进入调整模式；一次撤销可移除本次插入。
6. 选择贝塞尔图元后验证开口/闭合与独立用例一致；切换其他图元后选中闭合曲线，顶部仍能操作其接点，不受当前新建工具影响。

## 通用回归

本轮菜单与多实例 UI **待人工验收**，以下步骤使用新版菜单；旧章节的同名按钮现位于用例菜单和右侧用例工具。

1. 启动/加载文件后应仅显示“文档预览 · 未选择交互实例”，箭头光标，点击画布不会绘图，F5/Delete/Ctrl+Z/Y 不修改实例；选择实例节点后才显示对应交互模式。返回文档节点或切换文档标签应停用交互、清除对象选择并取消草稿，保留已完成数据；预览仍可平移缩放。
2. 文件 → 新建文档，确认空文档；用例 → 添加用例实例分别添加多边形与贝塞尔，再添加第二个同名实例。主动添加会选中新实例；树应呈现文档/实例/对象，切换只显示当前实例，几何、模式、视图和历史互不影响。
3. 在树单击对象，应高亮并进入调整模式；双击定位。右侧修改对象名称、颜色、线宽、文字和控制点；平滑曲线的坐标调整仍镜像联动，一次持续输入只撤销一步。点击文档/实例节点显示对应名称与信息。
4. 右键删除对象后 Ctrl+Z 恢复；删除实例后用编辑 → 撤销文档管理恢复其数据与原历史。在另一个实例继续绘制后再撤销文档重命名，几何不能倒退；管理撤销完成后回到文档预览，先重新选择实例再编辑。
5. 保存包含多个实例的文档，加载后全部保留、历史重新开始。导入版本 1 文件后 Ctrl+S 默认另存，原文件保留；检查新文件是可读版本 2 JSON。
6. 打开 `tests/scenarios/workspace-multi.json`，第三个实例应标记不可用，数据可保存，其他实例可用；选择匹配的插件目录后重试。F5 只重置当前明确选中的实例，错误时原实例保留，保存提示写入整个文档。
7. 文本输入尚未失焦就保存/切换实例，已输入属性应保留；未完成绘图取消。菜单与快捷键不应误触画布，文本框中 Delete/Ctrl+Z 不应删除或撤销图形。
8. 视图菜单隐藏/恢复面板，拖分隔条并重启确认记住布局；恢复默认布局应复位，文档不因布局或视图变化变脏。复验关闭、重载、退出的保存/放弃/取消及多文档逐项保存。

- 模式按钮应标记“当前”，画布标签显示模式及下一步操作；绘制时画布内为十字，离开后恢复指针，临时平移时显示移动光标。
- 已落点后重复点击当前模式不应取消；真正切换时取消预览并短暂提示，已完成对象保留。Esc、撤销重做、多标签及 F5 后反馈应与实际模式一致。

- 调整模式拖动图形主体应整体平移；空心封闭图形内部也可拖动。拖控制点只调整该点，Alt+拖动强制整体平移。
- 小于 3 像素的抖动不产生修改；Shift+拖动约束水平/垂直，Esc 完整取消，一次拖动一步撤销。
- 方向键微移选中图形，每步 1 屏幕像素，Shift 为 10 像素；中键/空格+左键仍是移动视图。

- 保存再加载后，图形、配置和自定义对象仍可编辑。
- 旧三角形/三次曲线文档可加载，缺失的新配置获得默认值。
- 同一用例的多个实例互不影响；F5 按既有保存提示流程重载当前实例。

## 脚本路径与按钮含义

1. 启动新版 exe，用例 → 打开用例目录选择仓库根目录的 `cases/`，确认诊断中的目录/路径与“编辑当前实例脚本”均对应选中的文件。
2. 修改该文件的名称、控件文字或辅助模块并保存；选择“应用脚本修改并重置当前实例”（F5），确认仅当前实例重置、文字更新，添加实例菜单中的用例名称更新，自定义实例名称保留。
3. 修改名称后只选“更新用例列表”，确认添加实例菜单更新，已有文档、实例名称及画布数据仍保留原样。
4. 故意产生 Lua 错误后应用，确认原实例保留；修复后再次应用，确认旧错误消失。
5. 切换到另一个用例目录，确认旧画布的 F5 和编辑入口仍指向原文件；重启后记住目录，“使用内置用例”恢复 exe 旁示例。
6. 取消目录选择不改变当前目录；空目录允许添加用例，缺失目录和编辑器失败显示诊断。验证系统编辑关联与无关联时的记事本回退。

自动化结果见 [测试记录](testing.md)。物理跨屏 DPI、系统文件对话框的人工验收仍独立保留。
