# 需求规格

状态：首版需求及菜单/多实例文档增量。日期：2026-10-28。

本文件记录已确认的产品行为；技术取舍见[决策记录](decisions.md)，实施默认与接口草案见[架构设计](architecture.md)。

## 1. 产品定位

构建一个类似画图软件的轻量二维测试工具，用于快速开发、运行和调试图形绘制与鼠标键盘交互演示。

“绘制用例”是完整的交互演示模块，拥有自己的数据、控件、交互模式、默认模式和操作逻辑。例如三角形用例默认连续绘制新三角形，点击按钮进入调整模式后，可以选择并移动三角形顶点。

工具既要方便终端使用，也要通过 SDK 降低用例作者的重复开发工作。技术选型依据是插件编写便利性、绘制与计算效率、使用简单性和依赖体积，不以本机已安装的软件决定方案。

## 2. 首版约束

| 项目 | 已确认要求 |
| --- | --- |
| 平台 | 仅 Windows，独立桌面程序 |
| 维度 | 仅二维，不考虑三维 |
| 用例开发 | Lua 脚本；修改控件、模式、绘制及交互逻辑无需重新编译 |
| 编辑方式 | 外部编辑器；工具提供 F5 和重载菜单、错误显示 |
| 典型规模 | 百到千级图形对象；以实际测试验证响应性 |
| 算法接入 | 首版通过 Lua 与内置 SDK 完成，不提供原生算法模块扩展 |
| 依赖原则 | 第三方库尽量少而小，避免大型框架和不必要的功能 |
| SDK 风格 | 组合型：提供常用图形与编辑能力，同时开放底层绘图及事件接口 |
| 控件编写 | Lua 直接调用控件 API，支持动态控件和联动 |

“用例无需编译”适用于日常 Lua 开发；修改 C++ 宿主或 SDK 的原生实现仍需要构建应用。

## 3. 画布与实例

- 使用文档标签，每份文档包含多个独立用例实例；管理树切换活动实例，中间只显示该实例画布。
- 同一用例可打开多份，各自的数据、参数、选择、模式和历史互不影响。
- 新建文档为空；通过用例菜单添加实例，初始化数据并进入默认模式。
- 切换文档或实例不重置数据；属性编辑先提交，未完成绘制取消。
- 启动、加载、切换文档标签及选中文档节点时，只预览记住的实例，不自动进入交互模式；选择实例/对象或主动添加实例后才启用交互。文档预览允许平移缩放，不路由用例事件、显示绘制光标或执行实例编辑快捷键；返回文档节点取消草稿并清除选择，实例模式保留待下次激活。
- 画布为无限二维视图，新建时无需指定宽高；窗口尺寸决定当前可见区域。
- 统一采用数学坐标：X 向右、Y 向上。SDK 负责屏幕与世界坐标转换。
- 支持平移、缩放与适应内容。具体快捷键在实现时统一并写入使用文档。
- 清空只作用于当前实例的可编辑内容，并形成一条可撤销操作；用例定义如何清空自己的自定义内容。

## 4. 绘图与交互 SDK

首版提供点、线段、折线、三角形、矩形、圆、椭圆、多边形、贝塞尔曲线和文本，支持颜色、线宽和填充。

文本不使用线宽，提供独立字号（6–256 屏幕像素）及文字/颜色属性。绘制、测量、拾取和选择框必须使用同一字号；连续修改一次撤销，保存加载保持大小。无字号的旧文本沿用原宿主字体，新建文本字号可单独配置，不改变已有文字。

三种示例扩展为可配置工具：多边形支持 3–256 个顶点及自由结束；贝塞尔支持 1–32 阶，阶数决定控制点数量；Gallery 由用户选择图元或自定义对象后在画布交互创建。保留旧用例标识和既有文档，创建设置应用于后续图形。

SDK 提供坐标转换、命中检测、选择反馈、控制点、拖拽预览、交互模式切换及取消操作。常规用例可以复用这些能力；特殊图形或算法演示可以使用底层绘图与输入接口。

调整模式中，选中对象使用外侧金色选择框和空心控制点，不用高亮色重画描边、填充或文字；改色及透明度预览保持可见，取消选择后恢复原样。选择框按实际绘制范围、线宽、点半径和文本测量留出屏幕像素间距；贝塞尔辅助线位于对象下层。反馈不修改文档样式或产生历史。文本按实际显示的矩形范围拾取，支持从文字区域拖动并保留点击偏移，一次拖动只记录一步。

用例可以自行定义模式及切换条件。SDK 应使“绘制模式连续创建对象，调整模式编辑控制点”成为容易实现的常见流程，而非要求每个用例重复实现完整编辑器。

控件范围包含按钮、输入框、滑块、复选框和下拉框。控件及其绑定逻辑直接写在 Lua 中。

## 5. 撤销与重做

| 操作 | 是否进入历史 |
| --- | --- |
| 创建、删除、修改图形 | 是 |
| 移动顶点或控制点 | 是；一次完整拖动只记录一步 |
| 修改持久化用例参数或自定义数据 | 是 |
| 清空画布 | 是 |
| 切换交互模式、改变选择 | 否 |
| 平移、缩放视图 | 否 |

- 每个实例拥有独立历史。
- 文档/实例重命名、实例添加/删除使用独立文档管理历史；撤销删除恢复原会话及其编辑历史，不回退其他实例的几何修改。历史有界，不持久化。
- 取消拖拽或未完成的编辑应恢复操作前状态，不产生历史记录。
- 撤销后执行新的编辑，原重做分支失效；无实际数据变化不应生成空记录。
- SDK 提供编辑事务，使自定义用例数据也能接入撤销重做。未纳入 SDK 状态和事务的数据不能承诺自动恢复。

## 6. 保存与加载

- 保存单位为当前文档及其全部实例，不包含其他文档标签。
- 保存用例标识与数据版本、可编辑图形、自定义状态、持久化参数及视图位置和缩放。
- 保存数据用于继续编辑，文档不是画布截图，也不打包用例源代码。
- 文档不保存撤销历史；选择与临时拖拽状态无需持久化。
- 加载成功后创建新标签，恢复数据与视图，以新的历史起点继续操作。
- 缺少插件、实例数据版本不兼容或加载回调失败时，保留不可用实例的原始数据并允许重试，其他实例继续使用；无效容器文件整体拒绝，不破坏已有标签和源文件。
- 文档格式采用版本化 UTF-8 JSON，首版扩展名为 `.drawer.json`，实际字段见架构与 SDK 文档。
- 保存时使用两空格缩进、结构换行及末尾 LF，中文保持 UTF-8。容器版本 2 保存名称和实例数组；版本 1 单实例文档可导入，首次保存默认另存为，不自动覆盖原文件。

## 7. 修改与重新加载用例

1. 用户在外部编辑器修改 Lua 文件。
2. 在当前实例按 F5 或选择用例 → 应用脚本修改并重置当前实例。
3. 工具检查并初始化新脚本；成功后替换当前实例，清空原数据和历史，进入默认模式。
4. 重载失败则保留原实例，显示错误信息及可获得的文件、行号和调用栈。

重载只作用于当前实例，同文档内其他实例也保持原状态。重载、关闭等会丢弃未保存数据的操作提供保存、放弃和取消入口；保存作用于整份文档。

开发和发布统一显式选择用例目录并记在本机，默认使用 exe 旁示例；SDK 随宿主提供。界面显示并允许用编辑器打开当前脚本。“更新用例列表”和切换目录不重置已打开画布，F5 与编辑入口始终绑定原文件。

## 8. 示例与验收

### 多边形用例（原三角形）

- 默认绘制模式，设置 3–256 个顶点后自动完成，或自由落点后手动完成；默认三个顶点仍可创建三角形。
- 按钮切换绘制与调整模式。
- 调整模式支持顶点选择、拖动预览、提交及取消。
- 创建、移动、清空均可正确撤销重做；保存加载后仍可调整顶点。

### 贝塞尔曲线用例

- 创建曲线并显示辅助线和控制点。
- 阶数可设置为 1–32，需要阶数加一个控制点；不同阶数的对象可共存并独立编辑。
- 支持控制点编辑、模式切换和参数控件。
- 新建时选择开口或普通闭合；闭合支持 3–32 阶，点击阶数个独立控制点，自动补齐与起点重合的末端。开口仍支持 1–32 阶。
- 调整模式在顶部显示选中曲线的阶数、闭合状态及闭合/断开操作。闭合保持阶数，将末端合并至起点；首尾只显示一个接点手柄，拖动首尾联动。
- 断开只解除联动，端点初始重合，拖动接点优先拉开末端；撤销可恢复闭合前形状。创建设置不改变旧对象，低阶新建切换闭合时自动升为三阶并提示，低阶旧对象保持原阶数。
- 普通闭合允许拐角；四阶及以上可勾选独立的“平滑接点”，接缝两侧控制点镜像联动，拖接点时两侧一起移动。取消平滑保持形状，断开同时解除平滑；Gallery 复用相同行为，不新增依赖。
- 新建平滑闭合点击阶数减一个独立点，自动补齐另一侧切向与终点；启用新建设置时低于四阶自动调整并提示。已有低阶对象不自动改阶，零切向输入提示重试或先拉开控制点。
- 展示 SDK 标准编辑能力与底层辅助绘制能力的组合。

### 图元与自定义对象用例

- 从空白画布选择点、线、折线、三角形、矩形、圆、椭圆、多边形、贝塞尔、文本或自定义十字后交互创建。
- 提供与所选类型相关的点数、阶数、文字、大小、颜色、线宽和填充设置。
- 保留可显式插入、可撤销的参考图元场景；切换工具清除未完成预览并进入绘制模式。

### 通用验收

- 同一文档内同名实例及不同文档互不影响。
- 文档往返后图形和用例数据一致，视图恢复，历史重新开始。
- Lua 语法错误、运行错误和重载失败有可定位的提示。
- 使用代表性的千级对象场景验证响应性；已执行的批量数据提取测量见测试记录，尚不宣称 GPU 帧率或完整交互性能已获人工验收。

## 9. 首版不包含

三维、图像导入显示、原生算法模块、完整工作区保存、撤销历史持久化、自动脚本热更新、内置脚本编辑器和完整 IDE 功能。

## 10. 菜单、管理器与属性

全局命令归入文件、编辑、用例、视图、帮助。左侧树呈现文档、实例、持久化对象；单击选择并高亮，双击对象定位，右键提供对应命令。右侧随选择显示文档/实例名称及信息、对象名称/样式/文字/控制点，以及该实例原有用例控件。自定义用例通过 `edit_mode` 声明调整入口，未声明时对象仅查看，避免误触绘制。

首轮单选，支持实例增删、重命名、对象删除和定位，不包含多选、显隐、锁定、排序或跨实例移动。面板宽度与显示状态可调整、恢复默认并保存在本机，不能污染文档脏标记。详细契约见[实施方案](workspace-ui-plan.md)。
