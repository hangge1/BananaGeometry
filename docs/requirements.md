# 需求规格

状态：首版需求基线。日期：2026-10-27。

本文件记录已确认的产品行为；技术取舍见[决策记录](decisions.md)，实施默认与接口草案见[架构设计](architecture.md)。

## 1. 产品定位

构建一个类似画图软件的轻量二维测试工具，用于快速开发、运行和调试图形绘制与鼠标键盘交互演示。

“绘制用例”是完整的交互演示模块，拥有自己的数据、控件、交互模式、默认模式和操作逻辑。例如三角形用例默认连续绘制新三角形，点击按钮进入调整模式后，可以选择并移动三角形顶点。

工具既要方便终端使用，也要通过 SDK 降低用例作者的重复开发工作。技术选型依据是插件编写便利性、绘制与计算效率、使用简单性和依赖体积，不以本机已安装的软件决定方案。

## 2. 首版约束

| 项目 | 已确认要求 |
| --- | --- |
| 平台 | 仅 Windows，独立桌面程序 |
| 维度 | 仅二维，不考虑三维 |
| 用例开发 | Lua 脚本；修改控件、模式、绘制及交互逻辑无需重新编译 |
| 编辑方式 | 外部编辑器；工具提供 F5 和重载按钮、错误显示 |
| 典型规模 | 百到千级图形对象；以实际测试验证响应性 |
| 算法接入 | 首版通过 Lua 与内置 SDK 完成，不提供原生算法模块扩展 |
| 依赖原则 | 第三方库尽量少而小，避免大型框架和不必要的功能 |
| SDK 风格 | 组合型：提供常用图形与编辑能力，同时开放底层绘图及事件接口 |
| 控件编写 | Lua 直接调用控件 API，支持动态控件和联动 |

“用例无需编译”适用于日常 Lua 开发；修改 C++ 宿主或 SDK 的原生实现仍需要构建应用。

## 3. 画布与实例

- 使用多标签画布，每个标签运行一个独立用例实例。
- 同一用例可打开多份，各自的数据、参数、选择、模式和历史互不影响。
- 新建画布时选择用例，初始化其数据并进入默认模式。
- 切换标签只切换活动实例，不重置已有实例。
- 画布为无限二维视图，新建时无需指定宽高；窗口尺寸决定当前可见区域。
- 统一采用数学坐标：X 向右、Y 向上。SDK 负责屏幕与世界坐标转换。
- 支持平移、缩放与适应内容。具体快捷键在实现时统一并写入使用文档。
- 清空只作用于当前实例的可编辑内容，并形成一条可撤销操作；用例定义如何清空自己的自定义内容。

## 4. 绘图与交互 SDK

首版提供点、线段、折线、三角形、矩形、圆、椭圆、多边形、贝塞尔曲线和文本，支持颜色、线宽和填充。

SDK 提供坐标转换、命中检测、选择反馈、控制点、拖拽预览、交互模式切换及取消操作。常规用例可以复用这些能力；特殊图形或算法演示可以使用底层绘图与输入接口。

用例可以自行定义模式及切换条件。SDK 应使“绘制模式连续创建对象，调整模式编辑控制点”成为容易实现的常见流程，而非要求每个用例重复实现完整编辑器。

控件范围包含按钮、输入框、滑块、复选框和下拉框。控件及其绑定逻辑直接写在 Lua 中。

## 5. 撤销与重做

| 操作 | 是否进入历史 |
| --- | --- |
| 创建、删除、修改图形 | 是 |
| 移动顶点或控制点 | 是；一次完整拖动只记录一步 |
| 修改持久化用例参数或自定义数据 | 是 |
| 清空画布 | 是 |
| 切换交互模式、改变选择 | 否 |
| 平移、缩放视图 | 否 |

- 每个实例拥有独立历史。
- 取消拖拽或未完成的编辑应恢复操作前状态，不产生历史记录。
- 撤销后执行新的编辑，原重做分支失效；无实际数据变化不应生成空记录。
- SDK 提供编辑事务，使自定义用例数据也能接入撤销重做。未纳入 SDK 状态和事务的数据不能承诺自动恢复。

## 6. 保存与加载

- 保存单位为单个画布文档，而非整个工作区。
- 保存用例标识与数据版本、可编辑图形、自定义状态、持久化参数及视图位置和缩放。
- 保存数据用于继续编辑，文档不是画布截图，也不打包用例源代码。
- 文档不保存撤销历史；选择与临时拖拽状态无需持久化。
- 加载成功后创建新标签，恢复数据与视图，以新的历史起点继续操作。
- 缺少对应插件、数据版本不兼容或文件无效时，明确报错，不破坏已打开的实例和源文件。
- 文档格式采用版本化 UTF-8 JSON，首版扩展名为 `.drawer.json`，实际字段见架构与 SDK 文档。

## 7. 修改与重新加载用例

1. 用户在外部编辑器修改 Lua 文件。
2. 在当前实例按 F5 或点击重载。
3. 工具检查并初始化新脚本；成功后替换当前实例，清空原数据和历史，进入默认模式。
4. 重载失败则保留原实例，显示错误信息及可获得的文件、行号和调用栈。

重载只作用于当前标签，其他同名用例实例继续保持原状态。重载、关闭等会丢弃未保存数据的操作应提供保存、放弃和取消入口。

## 8. 示例与验收

### 三角形用例

- 默认绘制模式，完成一次三点输入后创建三角形并继续下一次绘制。
- 按钮切换绘制与调整模式。
- 调整模式支持顶点选择、拖动预览、提交及取消。
- 创建、移动、清空均可正确撤销重做；保存加载后仍可调整顶点。

### 贝塞尔曲线用例

- 创建曲线并显示辅助线和控制点。
- 支持控制点编辑、模式切换和参数控件。
- 展示 SDK 标准编辑能力与底层辅助绘制能力的组合。

### 通用验收

- 同一用例两个标签互不影响。
- 文档往返后图形和用例数据一致，视图恢复，历史重新开始。
- Lua 语法错误、运行错误和重载失败有可定位的提示。
- 使用代表性的千级对象场景验证响应性；已执行的批量数据提取测量见测试记录，尚不宣称 GPU 帧率或完整交互性能已获人工验收。

## 9. 首版不包含

三维、图像导入显示、原生算法模块、完整工作区保存、撤销历史持久化、自动脚本热更新、内置脚本编辑器和完整 IDE 功能。
