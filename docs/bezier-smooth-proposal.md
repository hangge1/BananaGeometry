# 贝塞尔平滑接点扩展

日期：2026-10-28。用户要求扩展此前留待增强的平滑能力；本轮范围为现有单段闭合贝塞尔的接缝，已实现并获用户人工验收确认及本地提交授权。验证记录见[测试记录](testing.md)。

## 交互约定

- 新曲线选择闭合后显示“平滑接点”复选框，默认关闭。启用后新建阶数至少为四阶，低阶新建设置自动升到四阶并提示，两项算一步撤销；不改变已有对象。
- n 阶平滑闭合点击 n−1 个独立控制点：起点、起点旁切向控制点、其余自由控制点。另一侧切向控制点和重合终点自动补齐；四阶点击三次即可。预览、提示与完成使用同一规则。
- 调整面板对四阶及以上闭合对象提供相同选项。启用时优先保留起点旁控制点，将另一侧改为镜像，提示形状可能变化且可撤销；已有三阶对象只说明限制，不自动升阶。
- 拖动任一侧切向控制点，另一侧保持镜像；拖共享接点时两侧一起平移，其余控制点不联动。切向控制点标注“切向”，显示辅助线，保持现有主体平移与 Esc 回滚行为。
- 取消平滑只解除镜像约束，形状保持不变；断开接点同时取消平滑。全部修改进入事务，支持一次拖动一步历史、保存加载、多画布隔离及 Gallery 共用。

## 数学与数据契约

使用对称切向约束，达到 C1 连续：`P[n]=P[0]` 且 `P[n−1]=2P[0]−P[1]`。这保证接缝两侧的一阶导数相同，不宣称曲率连续或全曲线无自交。单段至少四阶，避免三阶平滑闭环必然共线退化。

新增可选布尔 `smooth`，缺失或 `false` 保持旧行为；`true` 要求闭合、至少五个实际控制点、首尾一致及镜像切向。切向不能与接点重合：新建时提示重新落第二点；拖到接点的那一帧保持最后有效位置。对已有对象，若首侧切向重合而另一侧有效，则保留另一侧并补齐首侧；两侧均重合时提示先拉开控制点。文档校验采用双精度舍入容差，不静默修复非法保存数据。

SDK 约束与控件继续分别放在 `bezier.lua` 和 `bezier_ui.lua`；增加 `ctx:set_bezier_smooth(object,enabled)`，调用者负责事务。共享接点拖动依据原始快照计算，避免连续预览积累误差；整体平移后同步镜像关系。渲染、拾取和采样继续使用实际控制点，不新增依赖或替换细分算法。

参考：[贝塞尔端点导数与 C1 闭合条件](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/Bezier/bezier-der.html)。
