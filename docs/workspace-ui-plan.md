# 多实例文档与界面实施方案

已确认：文档包含多个独立用例实例，实例包含持久化图元；每实例独立画布、视图、模式、Lua VM 与编辑历史。布局为顶部菜单、左管理树、中画布、右属性、底部状态/诊断。首轮单选，支持增删、重命名、定位，不增加显隐、锁定或跨实例移动。

菜单分为文件、编辑、用例、视图、帮助；原用例列表进入菜单。图元选择切换所属实例并进入声明的调整模式，高亮与树双向同步；自定义用例未声明编辑模式时不强行改变其事件路由。右侧承接现有用例控件并提供通用对象属性及扩展回调。

文档选择与实例激活独立：启动、加载及切换文档标签后选中文档，只显示上次查看实例的预览，不启用交互模式。点击文档节点同样停用交互、清除对象选择并取消绘制草稿；只有明确选择实例/对象或主动添加实例才启用该实例交互。预览仅允许视图导航，使用箭头和“未选择交互实例”提示；F5、删除、清空及实例撤销不可用，不影响整份文档保存和管理历史。

新增版本 2 文档容器，保留版本 1 单实例快照作为会话数据接口。旧文件导入为一个实例，首次保存默认另存；缺失/失败用例保留原始数据并可重试，其他实例正常工作。保存整份文档，使用既有缩进 JSON 和原子替换。插件只从明确选择的目录解析，不跟随文档任意路径执行代码。

Ctrl+Z/Y 始终操作当前实例；文档名称、实例增删/重命名使用独立、有界的管理历史。被删除会话保留到管理历史淘汰，撤销恢复其编辑历史；保存点按持久化内容比较。关闭文档仍使用保存/放弃/取消，F5 仅重置当前实例。

实施顺序：容器与兼容编解码 → 会话对象接口与管理模型 → 菜单/管理树/属性面板 → 布局偏好与故障流程 → 自动化、原生截图及人工验收。沿用现有依赖，模块按职责拆分；测试及场景进入仓库，证据放入规范目录。人工验收后提交，不自动推送。
